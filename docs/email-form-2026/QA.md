# Branded emails and contact form verification

The final production build, global ESLint and scoped formatting checks passed. The email suites passed 27 tests using mocked delivery; password recovery passed 10 isolated MongoDB tests. The final HTTP integration suite passed 82 assertions, including inbox deep links, generic recovery responses, reset-token reuse rejection, old-session revocation, rejection of the previous password and successful login with a 512-character password whose escaped JSON exceeds 2 KB. All temporary integration resources were cleaned up.

Verified September 9, 2026. The contact form passed all 94 functional browser checks at 320, 390 and 1440px in dark and light appearance. The final select-value styling passed six additional layout checks. The owner notification and customer receipt passed five email preview checks.

The [form report](form-browser-checks.json) covers both custom dropdowns through pointer selection, keyboard opening, typeahead, End, Escape and focus restoration. Required project-type validation prevents submission, shows the inline message and focuses the visible trigger. Commercial and Residential query defaults, native FormData values, the exact Submit/Submitting… labels, disabled pending state, error retention, retry and success confirmation all passed. Both popup menus fit the viewport and produced no scoped axe accessibility or contrast violations.

Every inquiry request was intercepted before the page loaded and fulfilled with a synthetic response. The twelve mock requests never reached the application server; no inquiry was saved and no email was sent. The keyboard harness waits for Radix's asynchronous focus updates before confirming a highlighted option.

Visual review caught the initial missing padding around the selected value. The component now wraps Radix's value in a styled span. [Final placement checks](select-final-checks.json) confirm its padding, containment and popup geometry at all six viewport/theme combinations. The final screenshots use the `*-final.png` suffix; for example, [320px light timing menu](320-light-timing-final.png).

The [email preview report](email-preview-checks.json) covers both templates at 640 and 390px, plus a 390px owner notification containing long unbroken synthetic text.

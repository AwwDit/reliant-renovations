# Reliant — Visual direction study

Open [index.html](index.html) in a browser for the three full-size artboards and the whole-site design plan.

This is a proposed visual reset. It adds design artifacts only; it does not change public application routes, the owner dashboard, or the current experience components. The apartment in the artboard is an imagined setting. A connected 3D model and functioning guided/free navigation have not been delivered by this study.

- [Home artboard](assets/01-home.png): clear residential and commercial entrances.
- [Residential artboard](assets/02-residential.png): architectural depth and service information within an apartment journey.
- [Commercial artboard](assets/03-commercial.png): shaded CAD, selected construction details and a drawing-to-real-project story.
- [Experience blueprint](experience-blueprint.md): all public routes, interaction requirements, service chapters, mobile behavior and SEO boundaries.
- [3D asset feasibility](3d-asset-feasibility.md): sourced model options and the work required for a real walkthrough.
- [Prompts and references](prompts.json): complete prompts used with the built-in image-generation tool.

The PNGs are original generated visual references. WebP copies are optimized only for the review page. Production must retain the approved transparent logos and CAD monogram rather than extracting the generated branding from these artboards. Real project photography remains separate from the illustrative scenes.

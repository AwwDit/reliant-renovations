# Project gallery direction

This is an isolated, functional preview at `/concept`. It does not replace the main site.

Reading this as: a renovation contractor portfolio for homeowners and commercial clients, with strong photographic compositions and clear project browsing. Native CSS, Manrope, the existing blue identity, and authentic project images. Design variance 8, motion 4, density 4.

The visual device is a project shown at three scales: the overall renovation, a related room or elevation behind it, and a craftsmanship detail in the foreground. Overlap, different scales, restrained perspective and independent pointer movement communicate depth. Every photo opens a functioning project gallery. No generated rooms, CAD overlays, automatic slideshows or paid media generation.

Residential and Commercial are visible collection controls. Named projects are separately reachable in the project index. Full-size galleries include scope, captions and inquiry links. The portfolio reads live published data through the existing server-side data layer; there is no parallel content database.

All styles are scoped to `cg-*`. Light and dark share a neutral blue-grey palette. Reduced motion removes translation and entrance animations. Touch browsing uses ordinary buttons, with no hover-only information. The concept is explicitly noindex and is not included in the production sitemap.

This preview establishes project presentation for review. The current About, Contact, division and case-study routes retain their existing implementations until the new direction is selected.
